==========
Short URLs
==========

:Extension key:
   shorturls

:Package name:
   ueberbit/shorturls

:Version:
   |release|

:Language:
   en

:Author:
   Jens Jacobsen

:License:

:Rendered:
   |today|

----

Adds a "Short URL" button to the page module toolbar that lets editors create
and copy a short, redirect-based URL for the current page with a single
click. Short URLs can optionally be generated automatically whenever a new
page of a configurable page type is created.
