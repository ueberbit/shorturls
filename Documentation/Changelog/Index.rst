Changelog
=========

.. _changelog-1-0-0:

1.0.0
=====

Initial release.

*  "Short URL" button in the page module doc header to create a short URL
   for the current page and copy it to the clipboard
*  Short URLs are stored as regular :sql:`sys_redirect` records
*  Optional automatic generation of short URLs for newly created pages,
   configurable per site and page type
*  Supports TYPO3 v14.3 LTS and PHP 8.3 / 8.4
